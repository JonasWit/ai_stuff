# ai_stuff

Experiments, notes and small tools around AI.

## Structure

| Path | Purpose |
| --- | --- |
| `notes/` | Research notes, ideas, links worth keeping |
| `experiments/` | Small, throwaway prototypes |
| `tools/` | Scripts I actually reuse |

## Conventions

- Full coding rules for humans and AI agents: [`docs/zasady-ai.md`](docs/zasady-ai.md).
- Pure functions in the core, side effects pushed to thin edges.
- Tests first (TDD); a task is done only when the tests pass.
- Every experiment gets a short `README.md` explaining the question it answers
  and what the result was.
